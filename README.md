## Descripción
Este programa implementa el algoritmo de búsqueda binaria utilizando la técnica Divide y Vencerás. El objetivo es encontrar un número dentro de una lista ordenada de manera eficiente.

## Funcionamiento
1. Se solicita al usuario un número para buscar.
2. El programa toma el elemento central de la lista.
3. Si el número coincide, devuelve la posición donde se encuentra.
4. Si es menor, continúa la búsqueda en la mitad izquierda.
5. Si es mayor, continúa la búsqueda en la mitad derecha.
6. El proceso se repite hasta encontrar el número o determinar que no existe.
